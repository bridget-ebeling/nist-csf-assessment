# NIST CSF 2.0 Risk Assessment: Small Agricultural Business

A cybersecurity risk assessment of a sole-proprietor livestock farm in rural Tennessee, structured on the NIST Cybersecurity Framework 2.0.

**Report:** [NIST_CSF_Assessment_Holladay_End.pdf](NIST_CSF_Assessment_Holladay_End.pdf)

## What it covers

- **Scope:** devices, online accounts, home network, and business records for a one-operator farm
- **Identify:** asset inventory (computers, phones, network, storage, cloud and financial accounts, research data) and the risks it reveals
- **Govern:** roles, decision authority, and budget constraints
- **Protect:** password management, MFA, disk and drive encryption, backups, network administration, and third-party access
- **Detect, Respond, Recover:** sign-in monitoring, incident response readiness, and a real recovery from a hard drive failure
- **Action plan:** nine no-cost remediations in priority order and three items needing budget approval, each with a business case

## Key findings

| Finding | Severity |
| --- | --- |
| Computer running an unsupported operating system (Windows 10) | High |
| Many accounts rely on a single sign-in provider | High |
| Only one backup copy, stored on site | High |
| Router managed by the internet provider; owner cannot review settings | Medium |
| No written security procedures | Medium |

## Remediation completed

- **Google account hardening (Action 1):** verified 2-Step Verification, passkeys, phone prompt, and MFA on all recovery accounts; stored backup codes in a password manager; reviewed third-party app access.
